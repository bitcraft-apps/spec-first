# Examples

Each example is one complete run of `/sf:spec` → `/sf:implement` → `/sf:document`. The
`README.md` holds the prompt and the commands. The `output/` directory holds what the
workflow produced, including the artifacts in `output/.sf/`.

| Example | Domain | Stack |
|---------|--------|-------|
| [rate-limiter](rate-limiter/) | Backend service code | TypeScript, vitest |
| [csv-summary-cli](csv-summary-cli/) | Command line tool | Python, unittest |
| [search-input](search-input/) | Frontend component | React, TypeScript, vitest |

Start with the one closest to your work. The commands are the same in all three.
